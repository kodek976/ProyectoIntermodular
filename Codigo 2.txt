1. Sistema de Login
Validación estricta: Crearemos un objeto usuariosRegistrados en localStorage. Si el input del usuario no coincide con la base de datos, el script impedirá el acceso y mostrará un mensaje de error ("Usuario no registrado").

Gestión de sesión: Al iniciar sesión correctamente, guardaremos un token (o simplemente el nombre de usuario) en sessionStorage. Esto nos permitirá mantener al usuario dentro de la app sin que tenga que loguearse constantemente.

2. Inicio (Dashboard)
Persistencia de estado: Usaremos una función renderDashboard() que comprueba si existe una bicicleta en localStorage. Si data.bike es null, todos los contenedores permanecerán vacíos.

Simulación de tiempos (Progreso): Implementaremos un sistema de ticks con setInterval que aumente progresivamente una variable desgaste o tiempoUso de cada componente. Esto dará la sensación de que la información se rellena sola con el tiempo (por ejemplo, actualizando una barra de progreso cada 5 segundos).

Cierre de sesión: El botón de cerrar sesión simplemente ejecutará sessionStorage.clear() y recargará la ventana para redirigir automáticamente al Login.

3. Garaje
Ficha vacía por defecto: El componente de Garaje mostrará un formulario (<form>) por defecto. Solo cuando el usuario envíe el formulario se generará el objeto miBicicleta en localStorage.

Generación automática: Una vez enviada la información (ej. modelo de bici), un script generará un array de componentes (cadena, frenos, neumáticos) con valores de estado iniciales.

Edición: Cada componente tendrá un botón "Editar" que habilita un campo input sobre ese elemento específico, permitiendo sobrescribir los datos generados automáticamente si el usuario detecta un error.

4. Asistente (Chat)
Interacción: Crearemos un contenedor de chat con una ventana de historial y un input de texto.

Lógica de respuesta: Usaremos un switch o if/else en JavaScript que analice el contenido del mensaje. Por ejemplo:

Si incluye "freno": El bot responde con consejos de mantenimiento de frenos.

Si incluye "hola": El bot devuelve un saludo.

Por defecto: "No entiendo tu consulta, ¿necesitas ayuda con tu bicicleta?".
